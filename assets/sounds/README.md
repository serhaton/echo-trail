# Sound asset list

Every sound the game needs, by mode and level. Placeholders are fine during
development; replace them with royalty-free files keeping the **same file
name**, and nothing in code has to change.

**Format:** mono `.m4a` (AAC) or `.wav`, 44.1/48 kHz. Spatial sources
(targets, collectibles) **must be mono** so panning works properly. Ambience
can be stereo. Loops must loop seamlessly (no click at the seam).

**Choosing target sounds (from playtesting):** targets are much easier to
locate when they are **intermittent, with a sharp attack and rich
harmonics**: a water drop, a bird call, a music box. Continuous textures
(streams, wind) are harder to pin down; use them for ambience, not targets.
For pulse-mode targets supply a **single strike** (≤ 1 s, clean tail);
the game repeats it faster as the player gets closer.

Status: ⬜ missing · 🟨 placeholder · ✅ final
